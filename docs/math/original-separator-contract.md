# Original finite separator compiler and message passing

The source is original `1-10.pages`, SHA-256 `0ad4cd0c72cdb8fac573b3bfd262d86d9580a8218a98657c828b01eaba92d970`. Native Prompt 3 paragraphs 7423–10005 were fully read with attached tables. Prompt 4 paragraphs 10074–10166 complete the certificate and quotient-composition proofs missing from Prompt 3's body. Relevant objects are `ALG-DS1`, `ALG-DS3`, `THM-DS19.1`, `THM-DS20.1` and `THM-DS13A`.

`oma.optimization.separator.Region(name, children, choices)` declares a tree node and its ordered children. Each named local choice supplies a complete map from child-state tuples to an output state in the node's finite carrier. Leaves have nullary choice maps. `compile_separator(carriers, regions, direct_outputs, root_region=..., context_root=...)` validates a tree with no disconnected nodes, cycles or repeated physical children, then compiles the complete typed operation theory with FDQA. Shared physical entities require explicit joint boundary state; reusing a child reference does not establish physical sharing.

All legal sibling states, all local choices and all parent contexts participate in contextual refinement. The supplied terminal reports must retain required safety, applicability, evidence and joint scenario distinctions. A region that hides a shared resource load or an interacting geometry state can yield an incorrect physical model even if its finite table certificate checks. Separator completeness remains an explicit application obligation.

Postorder message passing visits each local-choice and child-message tuple. Every message stores an exact integer count of labeled source-choice assignments and a backpointer. Different local choice labels remain distinct realizations even when their denotations coincide. Undefined and defined infeasible states are retained. Reconstructing a semantic witness does not prove that its represented physical realization fiber is nonempty.

`verify_separator` independently checks the FDQA certificate, scans all original operation tuples through that checker, checks complete reachable quotient transitions and exact count recurrence, and evaluates every backpointer in the original uncompressed merge tables. It does not run the compiler's partition refinement, context search, message generator or witness selection. `reconstruct_separator_choices` retrieves one complete assignment from an already checked artifact.

`substitute_labeled_menu` first checks the certificate, evaluates each fully specified choice assignment, and returns its exact root profile under its original label. The caller applies its declared choice rule to the full labeled map. Original P3's blanket class-deduplication claim needs amendment A025: contextual replacement invariance does not imply invariance under deleting menu labels. Exact multiplicity counts alone do not license evaluating an arbitrary menu rule on a deduplicated set.

The metric report includes root storage, total stored messages, root bits, maximum nonroot bits, child join products and canonical serialized message bytes. These bytes exclude Python object overhead, input and FDQA tables, and peak working memory. Amendment A026 requires retaining root memory instead of bounding every node by a width defined only on nonroot separators.

The synthetic hotel benchmark reproduces projected bay/floor message counts 32, 126, 320 and 650. It counts all `192**4 = 1,358,954,496` labeled feasible bay assignments while retaining 1,224 messages across the seven supplied tree nodes. The original source's claim that all 192 assignments inhabit a fixed cost/schedule/facade stratum is unsupported: those metrics vary inside an aggregate signature. Under amendment A027 the benchmark explicitly removes those observations by an approved projection; it makes no fixed-stratum or physical-building claim.

`scripts/corpus_separator_benchmark.py` writes the full compressed certificate and separately recorded preparation, compilation and independent-check timings to `evidence/math/original-separator-hotel-floor-benchmark.json`. An independent aggregate count recurrence verifies every hotel root count; a smaller joint-scenario capacity fixture is additionally evaluated over every raw source assignment. Fourteen focused tests include randomized complete finite tables, preserved labels, source-table tampering, root memory and explicit failure semantics. No measured exhaustive-billion-assignment speedup is asserted.
