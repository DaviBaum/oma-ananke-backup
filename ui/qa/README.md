The navigation test warms up for two seconds, then renders an actual moving camera for ten seconds. The JSON records the scene, immutable state root, renderer, viewport, delivered frame intervals, and CPU submission timing. CPU submission timing is not a GPU completion timer. The later GPU record uses asynchronous `EXT_disjoint_timer_query_webgl2` samples every tenth measured render and rejects disjoint results. Desktop viewport overrides change browser scaling, so each record's actual renderer pixel ratio is authoritative. The 30 FPS gate refers to the measured mean for that scene, rather than a universal performance guarantee.
