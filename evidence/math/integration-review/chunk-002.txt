[1281] THM-SIR22 — Configuration-space freedom implies swept-volume nonintersection

[1336] Local-to-global theorems
[1337] THM-SIR43 — Join-tree local-to-global gluing
[1338] Let local-state bags \(B_i\) form a tree satisfying running intersection. Suppose selected local states agree exactly on every edge separator. Then there exists a global SIR state restricting to every local state.
[1340] Root the tree.
[1341] Initialize the global assignment with the root state.
[1342] Visit each child after its parent.
[1343] Agreement on the parent–child separator means all already assigned shared objects have equal values, versions, and relations.
[1344] Add the child’s nonseparator objects and relations.
[1345] By LEM-SIR8, any variable appearing in multiple bags occurs along a connected subtree, so its first assignment propagates consistently through every later separator.
[1346] No object receives conflicting assignments.
[1347] The final union restricts to each local state.
[1348] Thus a global state exists. ∎
[1349] THM-SIR44 — Pairwise overlap agreement may be insufficient on a cyclic cover
[1350] Let three local bags contain variables
[1351] \[ B_1=\{x,y\},\quad B_2=\{y,z\},\quad B_3=\{z,x\}, \]
[1352] with binary constraints
[1353] \[ x=y,\qquad y=z,\qquad z\neq x. \]
[1354] Every pair of bags has a compatible assignment on its overlap, but no global assignment satisfies all three constraints. Thus pairwise agreement without a valid running-intersection or global constraint check is insufficient. ∎
[1356] Contextual-interface theorems
[1357] THM-SIR45 — Router contextual equivalence is an equivalence relation
[1359] Reflexive: every computation equals itself.
[1360] Symmetric: equality of outputs is symmetric.
[1361] Transitive: if every output agrees between \(x_1,x_2\) and between \(x_2,x_3\), then it agrees between \(x_1,x_3\).
[1362] Therefore \(\equiv_{R\to A}\) is an equivalence relation. ∎
[1363] THM-SIR46 — Downstream factorization
[1364] For every \(f\in\mathcal F_{R\to A}\), there exists a unique map on quotient classes
[1365] \[ \bar f:Q_{R\to A}\to Y_f \]
[1367] \[ f=\bar f\circ q. \]
[1368] Proof. Define \(\bar f([x])=f(x)\). If \(x\sim y\), the definition of equivalence gives \(f(x)=f(y)\), so the map is well defined. The factorization is immediate. Uniqueness follows because \(q\) is surjective. ∎
[1369] THM-SIR47 — Coarsest exact router interface
[1370] Let \(a:X_R\to A\) be any representation through which every admitted computation factors. Then
[1371] \[ a(x)=a(y)\Longrightarrow x\equiv_{R\to A}y. \]
[1372] Proof. For each \(f\), write \(f=g_f\circ a\). Equal \(a\)-values give equal \(f\)-values for every admitted \(f\). Hence \(x\equiv y\). Thus every exact sufficient interface refines the canonical quotient. ∎
[1373] THM-SIR48 — Experiment-family expansion refines the quotient
[1375] \[ \mathcal F_1\subseteq\mathcal F_2, \]
[1376] then
[1377] \[ \equiv_{\mathcal F_2} \subseteq \equiv_{\mathcal F_1}. \]
[1378] Proof. Agreement on every computation in the larger family implies agreement on the subfamily. ∎
[1379] THM-SIR49 — A new objective can invalidate an old interface
[1380] Let the old interface preserve route length and penetration count. Let router states \(x,y\) have equal values for both but different assembly-family counts. [1381] THM-SIR50 — Bounded interface does not license exact consumption

[1393] \[ \pi_{\mathrm{view}}(x)=\pi_{\mathrm{view}}(y) \Longrightarrow f(x)=f(y). \]

[1398] Rewrite and dependency theorems
[1399] THM-SIR54 — Exact SIR transport preserves included semantics under commuting correspondence
[1400] Let rewrite correspondence \(\chi\) be total on every object consumed by computation \(f\), preserve types and versions, and satisfy a commuting square
[1401] \[ f_{v+1}\circ T_\chi=f_v. \]
[1402] Then transporting state \(x\) gives
[1403] \[ f_{v+1}(T_\chi x)=f_v(x). \]
[1404] Proof. This equality is exactly the commuting hypothesis evaluated at \(x\). The theorem’s substance is the explicit requirement that every consumed object lies in the preserved correspondence domain. ∎
[1405] THM-SIR55 — Incomplete correspondence requires set-valued output or UNKNOWN
[1406] Suppose old object \(o\) may correspond to either \(o'_1\) or \(o'_2\), and a downstream computation differs on them. A single exact transported value would choose one without evidence. The sound output is the set of possible transported values or UNKNOWN. ∎
[1407] THM-SIR56 — Incomplete invalidation is unsound
[1408] Let certificate \(c\) depend on obstacle \(o\). Move \(o\), but omit edge \(o\to c\) from the invalidation graph and reuse \(c\). Choose the movement so the certified route now collides. The reused certificate says PASS while the current state fails. Thus dependency omission can make incremental reuse unsound. ∎
[1409] THM-SIR57 — Dependency-directed SIR recertification equals cold recomputation
[1410] Assume:
[1411] every changed root is known;
[1412] \(D_{\mathrm{SIR}}\) is complete;
[1413] every descendant certificate is invalidated;
[1414] reused nodes pass version, scope, theory, experiment, and applicability checks;
[1415] recomputed nodes use the same deterministic checkers as cold computation;
[1416] cyclic checked subsystems are condensed into certified nodes.
[1417] Then incremental and cold checking agree on every SIR release root.
[1419] Condense checked cycles, producing a DAG. Take a topological order. At source nodes, changed values are recomputed identically, and unchanged reused values pass equality/applicability checks, so they equal cold values. Assume equality for all predecessors of node \(v\). If invalidated, both procedures run the same deterministic checker on equal inputs; outputs agree. If reused, dependency completeness proves no changed root can affect it, and applicability establishes semantic equality with the cold node. Induction reaches every release root. ∎

[1426] Optimization and complexity foundations
[1427] THM-SIR60 — A locally shortest route may be absent from every globally preferred design
[1428] Consider two equipment placements.
[1429] Placement \(A\): local route length \(2\), but equipment and structural consequences add cost \(100\).
[1430] Placement \(B\): local route length \(5\), with no additional cost.
[1431] The locally shortest route belongs to \(A\), whose total objective coordinate is \(102\); \(B\) has total \(5\). Under any authorized scalarization weighting those quantities equally, the local shortest route is absent from the globally preferred design. ∎
[1432] THM-SIR61 — Finite route realization contains an NP-hard subproblem
[1433] Consider the restricted problem:
[1434] exact finite embedded graph \(G=(V,E)\);
[1435] one multi-terminal net with terminal set \(T\subseteq V\);
[1436] every edge is geometrically certified and has nonnegative integer cost;
[1437] ask whether a connected route subgraph spanning \(T\) has cost at most \(B\).
[1438] This is exactly the graph Steiner Tree decision problem.
[1439] Reduction. Given any graph Steiner Tree instance \((G,T,B)\), create the identical SIR routing graph, assign zero-width envelopes and no additional constraints, and request a route subgraph of cost at most \(B\). A Steiner tree is a valid route witness, and any valid connected route witness is a Steiner subgraph that can be cycle-pruned without increasing cost. The mapping is polynomial and preserves YES/NO answers. Therefore this exact finite restriction is NP-hard. ∎
[1440] THM-SIR62 — Explicit witness-checking complexity
[1441] Let an explicit PCSIR witness contain:
[1442] \(N\) serialized objects;
[1443] \(E_D\) dependency edges;
[1444] \(E_H\) hypergraph incidences;
[1445] \(F\) factors;
[1446] local checker costs \(c_1,\ldots,c_F\);
[1447] \(G\) shared-identity comparisons.
[1448] Then a topological explicit checker runs in
[1449] \[ O\!\left( N+E_D+E_H+G+\sum_{i=1}^{F}c_i \right), \]
[1450] excluding the cost of generating the witness.
[1451] Proof. Deserialize and validate each object once, traverse each incidence and dependency edge once, perform each identity comparison once, and invoke each local checker once. Summation gives the bound. ∎
