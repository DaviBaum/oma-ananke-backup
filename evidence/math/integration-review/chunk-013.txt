[15282] 67. Generalized-Benders example
[15283] Let corridor width
[15284] \[ w\in[0,3]. \]
[15285] Continuous route-relaxation subproblem:
[15286] \[ \begin{aligned} \varphi_1(w) = \min_{q\ge0}\quad &q^2\\ \text{s.t.}\quad &q\ge3-w. \end{aligned} \]
[15287] Equivalently,
[15288] \[ g(w,q)=3-w-q\le0. \]
[15289] At
[15290] \[ w_0=1, \]
[15291] the optimum is
[15292] \[ q^\star=2, \qquad \varphi_1(1)=4. \]
[15293] Lagrangian:
[15294] \[ L(w,q,\lambda) = q^2+\lambda(3-w-q). \]
[15295] Stationarity at \(q=2\) gives
[15296] \[ 2q-\lambda=0 \Longrightarrow \lambda^\star=4. \]
[15297] The lower envelope is
[15298] \[ \begin{aligned} \Theta_4(w) &= \inf_{q\ge0} \left[q^2+4(3-w-q)\right]\\ &= \inf_{q\ge0} \left[(q-2)^2+8-4w\right]\\ &= 8-4w. \end{aligned} \]
[15299] Hence the exact valid cut for this class is
[15300] \[ \boxed{ \eta\ge8-4w. } \]
[15301] At \(w=1\), it is tight.
[15302] Now add a discrete alternate route class with cost
[15303] \[ \varphi_2(w)=1+0.1w. \]
[15304] The true routing value becomes
[15305] \[ \varphi(w) = \min\{\varphi_1(w),\varphi_2(w)\}. \]
[15306] At \(w=0\),
[15307] \[ \varphi(0)=1, \]
[15308] while the old class-specific cut gives
[15309] \[ 8-4(0)=8. \]
[15310] The cut is not valid for the expanded route universe. It remains valid only for route class 1 or a branch that forces that class.
