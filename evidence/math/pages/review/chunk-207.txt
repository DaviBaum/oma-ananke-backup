[21-30:P29024; UTF16 948149] [ \boxed{ \textbf{Optimizing every project independently does not in general optimize the infrastructure shared by those projects.} } ]
[21-30:P29025; UTF16 948285] The externality law is:
[21-30:P29026; UTF16 948309] [ \boxed{ \textbf{A project consequence remains physically real when it crosses the project boundary. Ownership boundaries and causal boundaries are not the same object.} } ]
[21-30:P29027; UTF16 948484] The higher-order law is:
[21-30:P29028; UTF16 948509] [ \boxed{ \textbf{The absence of pairwise harm does not prove the absence of cumulative harm. Some effects exist only when several individually acceptable projects operate together.} } ]
[21-30:P29029; UTF16 948696] The transfer law is:
[21-30:P29030; UTF16 948717] [ \boxed{ \textbf{Flows exchanged internally among projects cancel at the portfolio boundary when represented consistently. Internal circulation is not regional resource creation.} } ]
