[1-10:P2902; UTF16 123776] 7.6 Commutativity
[1-10:P2903; UTF16 123794] Serial composition is not generally commutative.
[1-10:P2904; UTF16 123843] For example, a pressure-reducing valve followed by a pump does not generally have the same boundary relation as the pump followed by the valve. Likewise, a construction event “install rack” followed by “close ceiling” is not equivalent to the reverse sequence.
[1-10:P2905; UTF16 124104] Parallel composition satisfies a symmetry law:
[1-10:P2906; UTF16 124151] [ p\otimes q \cong \mathsf{swap}(q\otimes p) ]
[1-10:P2907; UTF16 124198] when the components have disjoint internal names and no imposed cross-component constraints.
[1-10:P2908; UTF16 124291] Thus:
[1-10:P2909; UTF16 124297] serial composition is generally noncommutative;
[1-10:P2910; UTF16 124345] disjoint tensor composition is symmetric up to interface permutation;
[1-10:P2911; UTF16 124415] undirected gluing can be symmetric when its wiring relation and physical constraints are themselves symmetric.
[1-10:P2915; UTF16 124529] 7.7 Hiding and existential elimination
[1-10:P2916; UTF16 124568] DEF-F23 — Relational hiding
[1-10:P2917; UTF16 124596] Let (X,Z,Y) be finite typed variable sets and
[1-10:P2918; UTF16 124642] [ R \subseteq \mathsf{Val}(X) \times \mathsf{Val}(Z) \times \mathsf{Val}(Y). ]
[1-10:P2919; UTF16 124721] The hiding of (Z) is
[1-10:P2920; UTF16 124742] { (x,y): \exists z\in\mathsf{Val}(Z), \ (x,z,y)\in R }. ]
[1-10:P2921; UTF16 124800] The variables in (Z) become internal.
[1-10:P2922; UTF16 124838] LEM-F2 — Hiding preserves exact external behavior
[1-10:P2923; UTF16 124888] For every (x\in\mathsf{Val}(X)) and (y\in\mathsf{Val}(Y)),
[1-10:P2924; UTF16 124947] [ (x,y)\in\exists_ZR ]
[1-10:P2925; UTF16 124970] if and only if there exists an internal assignment (z) such that
[1-10:P2926; UTF16 125035] [ (x,z,y)\in R. ]
[1-10:P2928; UTF16 125059] This is the defining membership condition in DEF-F23. No approximation is introduced. ∎
[1-10:P2929; UTF16 125147] LEM-F3 — Commutation of independent hiding
[1-10:P2930; UTF16 125190] If (Z\cap W=\varnothing), then
[1-10:P2931; UTF16 125221] \exists_W\exists_ZR. ]
[1-10:P2933; UTF16 125250] For an external assignment ((x,y)),
[1-10:P2934; UTF16 125286] [ (x,y)\in\exists_Z\exists_WR ]
[1-10:P2935; UTF16 125318] holds exactly when
[1-10:P2936; UTF16 125337] [ \exists z,\exists w,\ R(x,z,w,y). ]
[1-10:P2937; UTF16 125375] Finite existential quantification commutes:
[1-10:P2938; UTF16 125419] [ \exists z,\exists w,\ R(x,z,w,y) \iff \exists w,\exists z,\ R(x,z,w,y). ]
[1-10:P2939; UTF16 125495] The latter is the membership condition for
[1-10:P2940; UTF16 125538] [ \exists_W\exists_ZR. ]
[1-10:P2941; UTF16 125563] Therefore the two relations are equal. ∎
[1-10:P2942; UTF16 125604] Hiding is one of ANANKE-F’s exact compression operations. It removes internal variables while retaining every possible externally visible relation.

[1-10:P2989; UTF16 127467] 8.4 Context typing lemma
[1-10:P2990; UTF16 127492] LEM-F4 — Context typing
[1-10:P2992; UTF16 127519] [ \Gamma\vdash p:\tau ]
[1-10:P2994; UTF16 127547] [ \Gamma\vdash C[-]: \tau\Longrightarrow\sigma, ]
[1-10:P2996; UTF16 127602] [ \Gamma\vdash C[p]:\sigma. ]
[1-10:P2998; UTF16 127638] Proceed by structural induction on the derivation of the context (C[-]).
[1-10:P2999; UTF16 127711] Base case
[1-10:P3001; UTF16 127724] [ C[-]=[-]_\tau, ]
[1-10:P3003; UTF16 127748] [ C[p]=p, ]

[1-10:P3005; UTF16 127804] [ \Gamma\vdash p:\tau. ]
[1-10:P3006; UTF16 127829] Serial-composition case
[1-10:P3008; UTF16 127861] [ C[-]=q\circ D[-]. ]
[1-10:P3009; UTF16 127883] The context typing derivation supplies:
[1-10:P3010; UTF16 127923] [ \Gamma\vdash D[-]: \tau\Longrightarrow (\alpha\rightsquigarrow\beta) ]
[1-10:P3012; UTF16 128000] [ \Gamma\vdash q: \beta'\rightsquigarrow\gamma ]
[1-10:P3013; UTF16 128049] with a type-compatible wiring
[1-10:P3014; UTF16 128079] [ \omega:\beta\cong\beta'. ]
[1-10:P3015; UTF16 128108] By the induction hypothesis,
[1-10:P3016; UTF16 128137] [ \Gamma\vdash D[p]: \alpha\rightsquigarrow\beta. ]
[1-10:P3017; UTF16 128189] The serial-composition typing rule therefore gives
[1-10:P3018; UTF16 128240] [ \Gamma\vdash q\circ D[p]: \alpha\rightsquigarrow\gamma. ]
[1-10:P3019; UTF16 128300] This is (C[p]).
[1-10:P3020; UTF16 128316] The case (D[-]\circ q) is analogous.
[1-10:P3021; UTF16 128353] Parallel-composition case
[1-10:P3023; UTF16 128387] [ C[-]=D[-]\otimes q. ]
[1-10:P3024; UTF16 128411] By the induction hypothesis, (D[p]) has the interface required by the parallel-composition rule. Applying that rule yields the declared result type.
[1-10:P3025; UTF16 128560] The case (q\otimes D[-]) is symmetric.
[1-10:P3026; UTF16 128599] Guard case

[1-10:P3029; UTF16 128650] The context derivation gives
[1-10:P3030; UTF16 128679] [ \Gamma\vdash\varphi:\mathsf{Prop}. ]
[1-10:P3031; UTF16 128718] By the induction hypothesis, (D[p]) has the required program type. The guard typing rule preserves that type.
