[15921] ALG-F1 — Normalize and independently check
[15922] Provenance: RECONSTRUCTED_CANONICAL_BODY. Normalizes a proposed formal foundations artifact, verifies versions, invokes the independent checker, and records an immutable verdict.
[15923] INPUT raw artifact a, state X, versions V
1 y <- canonical_normalize(a)
2 if parse fails: return REJECT(parse_core)
3 if versions(y) != V: return REJECT(version_core)
4 (verdict,witness) <- C_F(X,y)
5 persist hashes and exact scope
6 return (verdict,witness)
[15924] Correctness basis. Every accepted transition is independently checked; failure is returned as REJECT or UNKNOWN. Complexity: O(|a|+T_C).
[15925] ALG-F2 — Dependency-directed recertification
[15926] Provenance: RECONSTRUCTED_CANONICAL_BODY. Recomputes exactly the downstream closure of changed semantic roots for formal foundations.
[15927] INPUT dependency graph D, change roots Delta, cache K
1 Q <- Reach_D(Delta)
2 preserve K outside Q only after root equality
3 for u in topological_order(Q):
    K[u] <- derive(u,K[parents(u)])
    check(u,K[u])
4 compare release with cold-check contract
5 return assembled PCFC
[15928] Correctness basis. Every accepted transition is independently checked; failure is returned as REJECT or UNKNOWN. Complexity: O(|V_D|+|E_D|+sum_{u in Q}T_u).
[15929] ALG-F3 — Proof-carrying package builder
[15930] Provenance: RECONSTRUCTED_CANONICAL_BODY. Builds PCFC without deleting limitations, UNKNOWN results, waivers, counterexamples, or supersession records.
[15931] INPUT checked claims C, witnesses W, cores K, dependencies D, versions V
1 require scope, modality, assumptions, provenance for every claim
2 require independent witness for every ACCEPT
3 attach REJECT and UNKNOWN records
4 attach theory, experiment-family, checker, and source versions
5 compute package hash and fiber membership
6 return PCFC
[15932] Correctness basis. Every accepted transition is independently checked; failure is returned as REJECT or UNKNOWN. Complexity: O(|C|+|W|+|K|+|D|).

[16161] What Has Not Yet Been Proven
[16162] The chapter does not prove model completeness, universal real-world safety, correctness of unverified external data, future validity after theory change, or optimality outside the declared candidate and uncertainty families. It does not authorize downstream modal strengthening.
[16163] Open-World Limitation
[16164] A proof here establishes a proposition in the declared formal world. It is evidence about reality only while models, measurements, assumptions, interfaces, and evidence remain applicable.
