`oma.optimization.fdqa.compile_fdqa(carriers, operations, direct_outputs, context_root=...)` consumes finite named state sets indexed by program sort, complete `Operation(name, inputs, output, table)` tables, and one complete canonically serializable terminal report per state. Nullary operations are the source atoms. Every nonundefined state must have a grounded finite source derivation. Optional typed undefined markers remain distinct from defined infeasible states and propagate through operations. Partial tables, wrong sorts, omitted states, ungrounded representatives and nonabsorbing undefinedness are rejected.

Every operation argument position, with every possible fixed auxiliary argument tuple, generates a primitive context. All admitted contexts are finite compositions of these primitives. Refinement begins with direct terminal reports and repeatedly splits by successor block identifiers until stable. The result contains lifted operation tables, source representative DAGs, primitive coverage and a distinguishing context for every distinct same-sort block pair. Budgets return `UNKNOWN` without a quotient certificate.

`verify_fdqa` does not rerun refinement or the producer's context search. It checks source/table identity, partition coverage, uniform outputs, every original operation tuple against the claimed lifted transition, grounded source representatives, complete primitive generation, and each supplied distinct-block witness by replay. Congruence proves within-block equivalence; the witnesses prove that different blocks cannot be merged. `evaluate_compiled_term` evaluates typed source terms bottom-up using a previously verified artifact and rejects cyclic term graphs. Repeated implementation references do not imply shared physical entities.

The caller must construct complete terminal reports and bind the model, scenarios, intent, evidence queries, catalogs and experiment family in the context root. Original P2 repairs P1 to preserve each realization's **joint model/scenario trace**; separate scenario marginals lose correlation. Complete choice reports preserve the marked candidate, every selected competitor, incomparability and rejection tags across all admitted menus. Safety, sovereignty, evidence and applicability remain mandatory even when an objective ignores them. This module computes exactly over the supplied finite semantics; it does not infer those semantic completeness assumptions.
