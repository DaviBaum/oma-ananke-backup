# Original Boolean symbolic quotient compilation

Original `1-10.pages` Prompt 4, native paragraphs 10006–12808 with all attached tables, is fully read in historical chunks 25–32. Its source SHA-256 is `0ad4cd0c72cdb8fac573b3bfd262d86d9580a8218a98657c828b01eaba92d970`. `ALG-AB1`, `ALG-AB4`, `THM-AB10`, `THM-AB22` and the relevant `DEF-AB35` certificate obligations are instantiated by `oma.optimization.symbolic`.

`BooleanTheory(variables, gates, domain, outputs, contexts)` is a complete finite Boolean model. The ordered variable list contains between 1 and 128 distinct names. Gates are a topologically ordered DAG of `const`, `var`, `not`, `and`, `or` and `xor`. Every reference points to an earlier gate. The domain is an exact Boolean formula. Named output fibers pair a gate with its complete terminal observation; they must cover the domain without overlap. Equal observation values merge their fibers. Each context supplies one output expression per variable, interpreted simultaneously. The kernel proves that each context maps the entire domain into itself.

`compile_symbolic` interprets the circuit in reduced ordered Boolean decision diagrams. Exact context substitution computes preimages; conjunction and relative complement split blocks. All context/block splitters enter a finite fair worklist. The initial partition is the direct-output partition, so every accepted split respects contextual equivalence. Resource exhaustion returns `UNKNOWN` with no usable exact quotient. An empty domain has a separate disposition and no invented representative.

The full certificate contains ordered diagram nodes, block predicates, exact assignment counts, concrete representatives, quotient transitions and a finite distinguishing context for every pair of different blocks. `verify_symbolic` imports and validates the canonical diagram structure, reconstructs the authoritative circuit, checks partition coverage and disjointness, proves uniform terminal observations and each transition by exact empty-intersection tests, checks model counts, and replays distinguishing contexts on the supplied concrete representatives. It does not rerun partition refinement or the producer's witness search. The Boolean diagram operations and canonical serialization remain explicitly part of the trusted checker implementation; no proof-assistant mechanization is claimed.

The original forty-module example needs two corrections. Amendment A030 fixes two initial blocks plus three accepted nontrivial binary splits to five final blocks. Amendment A031 replaces its underspecified literal append operation with a declared total fixed-width operation: activate the first inactive module, preserving each `a XOR b = 1`, and leave an all-active state unchanged. This produces the stated saturated count increment while remaining inside the finite domain. It does not represent a physical append or an actual building alteration.

The measured fixture has 80 Boolean variables, 603 input gates and exactly `2**40 = 1,099,511,627,776` valid assignments. Its five class sizes are 1, 40, 780, 9,880 and 1,099,511,617,075. All ten pairwise context witnesses check. The full implementation stores 31,569 diagram nodes, including domain, operation and intermediate diagrams; it does not report the source's isolated 205 count-state estimate as actual memory use. Timings and the complete certificate are retained in `evidence/math/original-symbolic-forty-module-benchmark.json` and its linked artifact.

Fourteen tests cover exhaustive small XOR assignments, independent residual searches in eighteen random three-variable theories, totality and output-coverage failures, resource limits, output equality, empty domains and certificate tampering. The production compiler and checker use symbolic operations and witness paths rather than enumerating the concrete carrier. Input construction time, symbolic refinement time and independent checker time are measured separately. No speedup against an unrun trillion-assignment baseline is asserted.

This instantiates a finite Boolean part of CAQC. It does not infer complete engineering context theories, construct symbolic physics from IFC, establish physical model adequacy, implement arbitrary SMT, automatically choose a good domain, or guarantee compact diagrams on other inputs. Incremental expanded-theory reuse, general reduced-product analysis and approximate numerical cover semantics remain separate obligations.
